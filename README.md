# Employee Customer Analysis Platform

## Project Overview

A modular Python-based employee data analysis platform that performs
data ingestion, cleaning, numerical analysis, visualization, API
integration, relational data merging, and report generation.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Requests
- python-dotenv
- Git

## Pipeline

CSV Load
→ Data Inspection
→ Data Cleaning
→ NumPy Analysis
→ Pandas Analysis
→ Department Merge
→ REST API
→ Visualizations
→ Reports

## Project Structure

- data/raw/ - Raw datasets
- data/processed/ - Cleaned datasets
- outputs/charts/ - Generated charts
- outputs/reports/ - Markdown report
- src/data/ - Data loading and cleaning
- src/analysis/ - Data analysis
- src/visualization/ - Charts
- src/api/ - REST API client
- src/reports/ - Report generation
- src/utils/ - Exceptions and helper functions
